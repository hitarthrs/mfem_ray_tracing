# Simple curve / surface example outputs

Generated PNGs from:

```bash
cd python_experiments/simple_curve_examples

# Curves → outputs/curves/<name>.png  (use -n to save without opening a window)
python examples.py -c s_shaped -n

# Surfaces → outputs/surfaces/<name>.png
python surface_examples.py -s right_angled_squared -n
```

PNG files here are gitignored; this README keeps the directory visible in the repo.
